# Emailing Admin

Lokální projekt bez napojení na Git.

## Jak spustit

1. **Otevřít v prohlížeči přímo:**  
   Dvojklik na `index.html` nebo v prohlížeči Otevřít soubor → vybrat `index.html`.

2. **Přes jednoduchý lokální server (doporučeno):**  
   V této složce v terminálu:
   ```bash
   npx -y serve .
   ```
   Pak otevři v prohlížeči adresu, kterou vypíše (např. http://localhost:3000).

## Struktura

- `index.html` – vstupní stránka
- `styles.css` – styly
- `app.js` – skripty

Git zatím nepoužívej; napojení můžeš přidat později.
